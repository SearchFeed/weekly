## 前端技术
- [Node.js 7 月安全更新（HIGH 严重等级）](https://nodejs.org/en/blog/vulnerability/july-2026-security-releases)
  <br>Node.js 针对 26.x / 24.x / 22.x 系列发布安全更新，修复 HIGH 级别安全漏洞，所有生产环境 Node.js 开发者应立即关注更新。

- [Proxy 与 Reflect: 重新认识对象的底层工作方式](https://piccalil.li/blog/proxy-and-reflect/)
  <br>深入讲解如何拦截 JavaScript 对象的内部操作：为什么需要 Reflect，并以一个小型响应式状态系统收尾——本质上就是 Vue 3 响应式的思路。

- [用面向数据的设计做高性能解析器](https://www.arshad.fyi/writings/engineering-high-performance-parsers)
  <br>声称比 Oxc、SWC、Babel 更快的 JS 解析器，可在 Playground 试用，对构建工具链有参考价值。

- [Nuxt 4.5，全栈 Vue 框架大更新](https://nuxt.com/blog/v4-5)
  <br>一段时间以来最大的一版，Vite 8、Rspack 2、实验性 SSR streaming、新 useLayout composable，为 Nuxt 5 铺路；Nuxt 3 将于 7/31 停止支持。

- [Safari 推出 Web 开发者 MCP 服务器](https://webkit.org/blog/18136/introducing-the-safari-mcp-server-for-web-developers/)
  <br>Safari 27 beta 和 Technology Preview 247 中引入 MCP 服务器，允许 AI agent 直接连接 Safari 浏览器窗口进行调试，支持 DOM 访问、网络请求监控、截图、控制台输出、性能分析等 16 个工具。

- [Safari 26.6 发布，Wasm 流式编译增强](https://webkit.org/blog/18178/webkit-features-for-safari-26-6/)
  <br>WebAssembly.compileStreaming() 和 instantiateStreaming() 新增 compileOptions 参数，支持 Wasm JS String Builtins 的流式编译，并修复 8 个 bug 覆盖 CSS、Service Worker、Web Extension 等领域。

## AI 资讯
- [字节跳动发布 Seed Audio 1.0，音频生成从“会说”迈向“会创作”](https://seed.bytedance.com/seedaudio1_0)
  <br>字节跳动推出的 Seed Audio 1.0 标志着 AI 音频生成技术进入全新阶段，能够端到端生成完整的音频作品。该模型具备精准的时空编排、稳定的音色演绎和多语种支持等核心能力，显著降低了高质量音频内容的制作门槛。

- [阿里发布 Qwen-Image-3.0，支持 4.5K Token 超长输入与复杂图文生成](https://qwen.ai/blog?id=qwen-image-3.0)
  <br>阿里正式发布新一代图像生成基础模型 Qwen-Image-3.0，该模型支持最高 4.5K Token 超长文本输入，能够生成包含公式符号、几何图形、逻辑推导、多层UI界面等复杂内容，并原生支持 12 种语言和 20 余款字体渲染，进一步提升商业级图文内容生成能力。

- [腾讯 Miora AI 创意平台全量上线 多智能体协同重构内容生产流程](https://miora.design/)
  <br>腾讯旗下 AI 创意智能体平台 Miora 正式全量上线，其核心竞争力在于‘全链路’服务能力，能够有效解决AI生成内容中常见的‘风格漂移’问题，确保同一项目下不同物料的风格高度统一。

- [Claude Code 首次支持 iOS 模拟器](https://docs.anthropic.com/en/docs/claude-code)
  <br>Anthropic 推出了 Claude Code 的重大更新，首次支持 iOS 模拟器，提升了开发效率并简化了操作流程。

- [Kimi K3 开源，2.8 万亿参数登顶全球最大开源模型](https://github.com/MoonshotAI/Kimi-K3)
  <br>Kimi K3 的发布标志着中国在大模型领域取得了重要进展，其强大的性能和开源策略对 AI 行业产生了深远影响。

- [Google DeepMind 推出 Lyria 3.5 音乐生成模型](https://deepmind.google/models/lyria/)
  <br>Google DeepMind 在 Google Flow Music 平台上推出了新一代音乐生成模型 Lyria3.5，该模型在音乐性、歌词质量、人声表现力和创作控制力方面实现了显著提升，标志着 AI 音乐创作向专业应用场景的加速迈进。

- [WorkBuddy上线「人机双写」: AI 走出聊天框，坐进你的文档里一起干活](https://www.workbuddy.cn/)
  <br>WorkBuddy 推出的「人机双写」功能重新定义了人机协作的边界，让 AI 成为嵌入流程的数字同事，显著提升了办公效率，并推动行业进入同屏协作新赛道。

- [OpenAI 发布 Presence 企业级 Agent 部署平台](https://openai.com/index/introducing-openai-presence/)
  <br>OpenAI Presence 是一个企业级 AI Agent 产品，支持企业部署可靠的人工智能代理处理计费、保险理赔、IT 服务等工作，结合模型推理、企业策略和防护栏，支持语音和聊天两种交互模式。

- [美团发布 CatPaw 全场景 AI Agent 平台](https://tech.meituan.com/2026/07/28/CatPaw-LongCat.html)
  <br>美团正式发布搭载 LongCat 2.0 的全场景 AI Agent 平台 CatPaw，提供开箱即用的 AI 智能工作台与企业级 Agent 开发托管能力，从个人提效到企业智能化的全场景覆盖。

- [美团开源 LoHoSearch 与 MineExplorer](https://tech.meituan.com/2026/07/24/LongCat-LoHoSearch.html)
  <br>美团 LongCat 团队连发两个重要开源：LoHoSearch——下一代搜索智能体评测基准，使用知识图谱校准 AI 能力认知；MineExplorer——业界首个开放世界+分钟级长程任务评测基准，揭示多模态模型在长程规划等领域的能力缺口。

- [通义 Qwen3Guard 安全护栏模型](https://qwen.ai/blog?id=qwen3guard)
  <br>Qwen 系列首个安全护栏模型，提供 Gen（离线标注）和 Stream（实时流式检测）两个变体，三层严重度分级（Safe/Controversial/Unsafe），支持 119 种语言，安全性评测上达到 SOTA。

- [谷歌 AI 搜索占比一年翻倍](https://www.aibase.com/zh/news/29953)
