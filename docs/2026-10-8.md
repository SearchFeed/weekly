# 前端&AI技术双周刊-2026.10.08


## 前端技术
- [TanStack 发布 Redact 项目](https://tannerlinsley.com/posts/projecting-react)
  <br>TanStack 创始人 Tanner Linsley 发布 Redact，一个'React 的逻辑投影'，目标是 API 完全兼容但实现更简洁、包更小、性能更好，代价是不支持并发渲染。作为对 React 实现层面的重新思考，Redact 为理解 React 内部机制提供了独特视角，也测试了社区对替代实现的态度。

- [12 个替代 npm 包的 Node 内置模块](https://flaviocopes.com/node-builtins/)
  <br>Flavio Copes 系统梳理了 12 个可以替代 axios、dotenv、nodemon、chalk 等常见 npm 包的 Node.js 内置模块，并标注了在 Node 24 LTS 中的稳定性等级和潜在坑点。对于希望精简依赖、降低供应链风险的前端团队，这是一份非常实用的参考指南。

- [React-Redux 9.4 引入 useSignalSelector](https://github.com/reduxjs/react-redux/releases/tag/v9.4.0-alpha.1)
  <br>React-Redux 9.4 Alpha 加入基于 signals 的 useSignalSelector 钩子，通过追踪每个 selector 读取的状态，让 dispatch 只重新执行数据发生变化的 selector，解决大型应用中每次 dispatch 重跑所有挂载选择器的性能瓶颈。这是 Redux 在响应式状态管理方向的重要探索。

- [Cloudflare 发布 Vinext 1.0](https://blog.cloudflare.com/vinext-nextjs-on-vite/)
  <br>Cloudflare 发布基于 Vite 的 Next.js 重实现 Vinext 1.0，现已支持 Pages 和 App Router，并提供现有应用的迁移路径。作为 Cloudflare 自研 Vite 驱动的 Next.js 替代方案，Vinext 为 Next.js 用户提供了新的部署选择，也反映了 Vite 生态在框架层的持续扩张。

- [MSW 3.0 发布](https://github.com/mswjs/msw/releases/tag/v3.0.0)
  <br>Mock Service Worker 3.0 发布，全面转向 ESM-only，新增 Vite 插件、GraphQL 订阅支持，并可拦截页面导航和表单提交。作为前端 API 模拟的主流方案，MSW 3.0 的 ESM 化与插件生态对测试基础设施的现代化改造有直接影响。

- [TC39 三个迭代器提案同时进入 Stage 4](https://github.com/tc39/agendas/blob/main/2026/09.md)
  <br>在东京召开的 TC39 会议上，iterator chunking、iterator join 和 iterator includes 三个迭代器提案同时晋升 Stage 4，其中 includes 已在 Chrome 154 中落地。这标志着 JavaScript 标准库对迭代器协议的支持进一步完善，为链式数据处理提供了更优雅的原生能力。

- [Vite+ 1.0 发布](https://voidzero.dev/posts/announcing-vite-plus-1-0)
  <br>VoidZero 发布 Vite+ 1.0，一个 vp 命令即可统一管理 Node 运行时、包管理器、开发服务器、Lint、格式化、测试、构建和任务执行，配置集中在 vite.config.ts。配套的 vp migrate 可迁移现有 Vite、Vitest、ESLint 等项目，是前端工程化工具链一体化的重要一步。

- [Effect 4.0 重写发布](https://effect.website/blog/releases/effect/40)
  <br>Effect 4.0 是底层重写版本，号称最小包体积缩减 5 倍、每个并发任务内存占用减少 86%。该库擅长处理资源管理、并发、重试、类型化错误等复杂场景，在大型 TypeScript 工程中应用广泛，此次发布对可靠性敏感的开发者是重要更新。

- [Remix 3.0 正式发布](https://github.com/remix-run/remix/releases/tag/remix%403.0.0)
  <br>重建后的全栈框架 Remix 3.0 发布稳定版，最大的变化是不再强制依赖 React。作为 Remix 2 之后的重构版本，3.0 标志着 Remix 在框架路线上的重大转向，对前端框架生态格局影响显著，值得关注其后续生态发展。

- [Preact 11 正式发布](https://preactjs.com/blog/preact-11/)
  <br>Preact 11 时隔多年正式发布，带来改进的水合（hydration）、自动 ref 转发以及 ESM-only 包结构。作为 React 的轻量替代方案，Preact 11 进一步缩小了与 React API 的差距，对追求性能和包体积的团队是重要升级，官方同时提供完整的升级指南。

## 扩展阅读

- [Sindre Sorhus 因 AI 垃圾关闭外部 PR](https://bsky.app/profile/sindresorhus.com/post/3mwtgzhv7uk2t)

- [高级工程师'死亡螺旋'](https://sunilpai.dev/posts/the-senior-engineer-death-spiral/)
  <br>Cloudflare 工程师 Sunil Pai 撰文描述高级工程师的'死亡螺旋'：新角色中为了证明自己而长时间沉默做事，最终导致过劳甚至 burnout。文章直面资深工程师在换岗或晋升期的心理困境，对技术人管理精力和团队留住人才都有现实参考价值。

- [为什么开发者不'使用平台'？](https://nolanlawson.com/2026/10/03/why-dont-more-developers-use-the-platform/)
  <br>Nolan Lawson 撰文讨论一个长期困扰前端圈的问题：为什么开发者不愿意使用浏览器平台提供的能力，而更倾向自建抽象？文章从开发者心理、框架生态、兼容性焦虑等角度剖析'平台原语'被冷落的原因，对当前 Web 平台能力与框架关系的讨论很有启发。

## 资源推荐
- [pdfcn 复制粘贴式 PDF 组件库](https://www.pdfcn.dev/)
  <br>pdfcn 采用 shadcn 的思路做 PDF 生成，提供表格、页眉、列表、发票报告等可复制粘贴的组件。渲染基于 Takumi 或 Forme 两个 WASM 引擎，无需无头浏览器即可在浏览器端生成 PDF，为需要 PDF 导出能力的应用提供了轻量、现代的替代方案。

- [PR Comment Inbox 评审评论收件箱](https://humanwhocodes.com/blog/2026/09/introducing-pr-comment-inbox/)
  <br>Nicholas Zakas 发布的 PR Comment Inbox，为 GitHub 评审评论提供邮件式收件箱体验，支持线程聚合、已读/未读状态管理。对于在多个仓库间维护大量 open source 项目的开发者来说，这个工具能显著降低评审评论的跟踪成本，是 GitHub 原生通知体验的实用增强。

- [CVE Lite CLI 安全扫描工具](https://owasp.github.io/cve-lite-cli/)
  <br>OWASP 支持的开源安全扫描器，读取 lockfile 并对照 OSV 与 npm 安全公告，直接给出需要执行的 npm/pnpm/Yarn/Bun 升级命令，包括传递依赖问题应升级的父包。对前端团队来说，这是把依赖安全扫描融入日常开发流程的轻量利器，无需复杂配置即可获得可执行的修复建议。
