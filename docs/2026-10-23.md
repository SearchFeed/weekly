# 前端&AI技术双周刊-2026.10.23


## 前端技术
- [Miro 如何将 7 万条测试从 Jest 迁移到 Vitest](https://nothing-else.blog/blog/we-migrated-70000-tests-from-jest-to-vitest-yes-in-2-months)
  <br>Miro 团队分享在 2 个月内将 70,000 条测试从 Jest 迁移到 Vitest 的完整实践，包括迁移策略、踩坑与收益。对于正在评估测试框架迁移的前端团队，这是一份极具参考价值的一线案例。

- [Preact 11 发布：Hydration 2.0 与全新升级体验](https://preactjs.com/blog/preact-11/)
  <br>轻量级 React 替代方案 Preact 发布 11.0，引入 Hydration 2.0 以提升交互启动性能。对追求极小体积与高性能的场景，Preact 11 的新机制提供了更具竞争力的选择。

- [TanStack Start 1.0：全栈 React 框架达到稳定版](https://tanstack.com/blog/tanstack-start-1-0)
  <br>TanStack Start 1.0 正式发布，标志着这一全栈 React 框架达到生产可用。其与 Next.js 的差异化路线（更灵活的架构、类型安全优先）为 React 生态提供了新选择，值得关注其发展。

- [Chrome 推出声明式部分更新（Declarative Partial Updates）](https://developer.chrome.com/docs/web-platform/declarative-partial-updates)
  <br>Chrome 推出 Declarative Partial Updates 新特性，允许开发者以声明式方式实现页面局部更新，减少 JavaScript 体积与复杂度。这是浏览器平台层面对常见前端更新模式的原生化支持，值得了解其应用场景。

- [Deno 宣布加入 Cloudflare](https://deno.com/blog/cloudflare)
  <br>Deno 正式宣布加入 Cloudflare，这是 JavaScript 运行时格局的重要事件。Deno 的生态和 Cloudflare 的边缘计算能力结合，可能重塑服务端 JS 运行时竞争格局，社区对此讨论热烈。

- [React Native 0.88 正式发布](https://reactnative.dev/blog/2026/10/19/react-native-0.88)
  <br>React Native 0.88 带来架构与性能的多项改进。虽然近期 Coinbase 等大厂在考虑迁移出 React Native，但作为跨端开发的主流方案，其版本更新仍值得前端与移动端同学关注。

- [Node.js v26.12.0 与 v24.22.0 发布](https://nodejs.org/en/blog/release/v26.12.0)
  <br>Node.js 发布 v26.12.0（Current）与 v24.22.0（LTS），带来 V8 15.5 升级、配置文件和同步加载 ES 模块等改进。持续发布节奏说明 Node 生态仍在快速迭代，值得跟进运行时能力变化。

- [Next.js 修复两个严重 RCE 漏洞（含公开 PoC）](https://nextjs.org/blog/nextjs-security-update-october-14-2026)
  <br>Next.js 在 10 月 14 日发布安全更新，修复两个可导致远程代码执行（RCE）的严重漏洞，其中一个涉及 React Server Components 的上游缺陷，且已有公开 PoC 流出。所有 Next.js 用户应尽快升级，属于必须关注的安全事件。

- [Next.js 16.4 让 Cache Components 成为默认推荐](https://nextjs.org/blog/next-16-4)
  <br>Next.js 16.4 将 Cache Components 提升为推荐默认方案，并新增了面向 Agent 的编程工具能力。缓存策略从手动配置走向默认开箱即用，是 React 全栈框架在服务端渲染性能与开发体验上的又一次重要演进。

- [tsrs：Cloudflare 和 VoidZero 的 Rust 版 TypeScript 发布](https://blog.cloudflare.com/typescript-rust-port/)
  <br>Cloudflare 与 VoidZero 联合推出 Rust 编写的 TypeScript 移植版 tsrs，官方声称最高可实现 8 倍性能提升。这是继 Deno 后又一次对 JS 运行时底层的大规模重写尝试，对前端构建链路和类型检查速度有重大影响，值得关注。
