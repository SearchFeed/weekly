# 前端&AI技术双周刊-2026.11.20


## 前端技术
- [修复：npm 生态发现恶意包利用「安装后脚本」窃取环境变量](https://socket.dev/blog/malicious-npm-packages-env-exfiltration)
  <br>供应链安全公司 Socket 披露一批恶意 npm 包，利用 install 脚本窃取 CI 环境变量（含 token、密钥）。提醒团队审查依赖来源、锁定版本，并在 CI 中使用最小权限令牌。

- [pnpm 10：新增内容寻址存储校验与幽灵依赖防护](https://pnpm.io/blog/pnpm-10)
  <br>pnpm 10 发布，强化了内容寻址存储（CAS）的完整性校验，并新增对幽灵依赖（phantom dependencies）的默认防护选项。对大型 monorepo 的依赖治理与可复现构建是重要改进。

- [Bun 1.3：内置 Windows 原生支持与更快的包管理器](https://bun.sh/blog/bun-v1.3)
  <br>Bun 1.3 发布，Windows 原生支持从预览转正，`bun install` 在 monorepo 场景下的安装速度进一步提升。作为「全家桶」运行时，Bun 在工具链侧持续施压 Node/Deno 生态。

- [Safari 27.2：预览 CSS `text-wrap: balance` 增强与 WebGPU 更新](https://webkit.org/blog/18532/webkit-features-for-safari-27-2/)
  <br>Safari 27.2 技术预览带来 `text-wrap: balance` 的增强实现与 WebGPU 的多项更新，继续推进跨浏览器排版与图形能力的一致性，是关注跨端体验的前端工程师必读项。

- [React 19.3：为 Server Components 提供更细粒度的错误边界](https://react.dev/blog/2026/11/13/react-19-3)
  <br>React 19.3 发布，重点完善 RSC 生态：细粒度错误边界、流式渲染中断恢复，以及 `use` hook 的更多能力。对正在迁移到 App Router / RSC 的团队是重要的稳定性补强。

- [Vite 7 正式版：默认 Rolldown 打包，冷启动再提速](https://vite.dev/blog/announcing-vite7)
  <br>Vite 7 正式发布，默认打包器切换为 Rust 写的 Rolldown，开发服务器冷启动与 HMR 速度显著提升，并统一了构建与开发的一致性。作为前端工具链核心，Vite 7 的落地将影响大量项目的工程化升级。

- [TypeScript 6.0 Beta 发布：Go 重写编译器进入公开测试](https://devblogs.microsoft.com/typescript/announcing-typescript-6-0-beta/)
  <br>TypeScript 官方发布 6.0 Beta，Go 重写的原生编译器（tsgo）首次面向公众开放测试，类型检查与编译速度提升 10 倍量级。这是 TS 项目十年来最大的架构变革，现有代码库迁移的兼容性表现值得关注。

- [Node.js 27 进入 Current：默认开启模块同步、V8 15.8](https://nodejs.org/en/blog/release/v27.0.0)
  <br>Node.js 27 发布首个 Current 版本，升级 V8 至 15.8，默认开启 `--experimental-strip-types`，并引入新的 `node:sqlite` 稳定性提升。年度发布节奏下，Node 27 将接力 Node 26（活跃 LTS），是选型与升级路径的关键节点。

- [Chrome 158 稳定版：CSS 锚点定位与视图过渡增强](https://developer.chrome.com/blog/new-in-chrome-158)
  <br>Chrome 158 稳定版发布，CSS 锚点定位（anchor positioning）默认开启，配合视图过渡（View Transitions）支持同文档多元素过渡，让复杂 UI 动画无需 JS 库即可实现。此外新增 `Scroll-driven Animations` 的性能优化，对交互型前端是实打实的效率提升。

- [TanStack Redact：更瘦的 React 浏览器运行时](https://tanstack.com/blog/introducing-tanstack-redact)
  <br>TanStack 发布构建插件，用更小的浏览器端重实现替换 React 和 React DOM，无需改代码即可用，支持 Vite、Start、Vinext 和 Next.js。客户端构建体积减少 20-70%，但渲染是同步的。社区讨论其与 Preact 的区别及 re-render CPU 成本。

- [从「写代码」到「编排 Agent」：前端工程师的技能迁移](https://martinfowler.com/articles/2026-ai-era-frontend/)

- [前端框架「AI 原生」之争：RSC、Signal 与编译时方案](https://www.smashingmagazine.com/2026/11/ai-native-frontend-frameworks/)

- [Biome 3.0：一体化 JS/TS 工具链，lint + format 统一](https://biomejs.dev/blog/biome-v3/)
