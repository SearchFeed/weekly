## 前端技术
- [Vite 修复严重远程代码执行漏洞：涉及向网络开放的开发服务器](https://github.com/vitejs/vite/security/advisories/GHSA-p4f5-76q4-ffq7)  
  Vite 于 11 月 10 日发布安全公告，修复虚拟模块处理中的远程代码执行漏洞，影响通过 --host 或 server.host 显式向网络开放的开发服务器。修复版本包括 8.3.7、8.2.5、8.1.7、7.3.8 和 6.4.6。

- [Node.js 发布 11 月安全更新：覆盖 26.x、24.x 和 22.x](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases)  
  Node.js 于 11 月 11 日发布安全更新，覆盖 26.x、24.x 和 22.x 三条版本线，修复涉及 HTTP/2、HTTPS、TLS 和权限模型的多项问题，并更新相关依赖。不同漏洞的受影响版本和触发条件已在官方公告中分别列明。

- [Storybook 11 Beta 发布：提供 Agent 技能、插件与无界面 CLI](https://storybook.js.org/blog/storybook-11-beta/)  
  Storybook 于 11 月 9 日发布 11 Beta，新增面向编码 Agent 的官方技能、Claude 和 Codex 插件，以及无需启动完整界面即可使用的 CLI 工具。更新覆盖组件文档查询、Story 编写、测试与界面审阅，并引入类型安全的 CSF 4。

- [Modern Web Guidance 1.0 发布：为编码 Agent 提供 Web 平台知识](https://developer.chrome.com/blog/modern-web-guidance-v1)  
  Google 于 11 月 10 日发布 Modern Web Guidance 1.0，将 Web 平台最佳实践、浏览器兼容性与 Baseline 信息整理为编码 Agent 可使用的技能。正式版新增代码库现代化扫描流程、扩充经过专家审核的指南，并由 Chrome、Firefox 和 Edge 团队共同参与。

- [Jeasx 3.0.1 发布：更新 Fastify 并修复流式渲染问题](https://www.jeasx.dev/news)  
  Jeasx 于 11 月 11 日发布 3.0.1，包含 Fastify 安全更新，并修复路由返回 null 的处理、开发与生产环境文件访问差异，以及深层 Promise 异常处理和流读取后未释放锁的问题。其服务端 JSX 流式输出能力已在此前的 3.0 中引入。

- [用决策模型构建理解用户意图的界面](https://agustinbarrientos.com/writing/senior-eye/interfaces-that-understand-what-we-want)  
  Agustin Barrientos 于 11 月 9 日发表技术文章，介绍让 AI 从开发者预设的选项中选择操作，将自然语言意图映射到受约束的界面行为。文章结合筛选、快捷操作等案例讨论实现方式，并介绍实验中的 Chrome Decisions API。

## 资源推荐
- [Site Seeing：在软键盘、分屏等场景下预览响应式布局](https://ishadeed.com/article/beyond-the-viewport/)  
  Ahmad Shadeed 开发的网页布局预览工具，覆盖软键盘展开、分屏、停靠开发者工具、垂直标签页和打印等使用场景，帮助检查常规桌面与手机尺寸之外的布局表现。作者介绍文章发表于 11 月 5 日。

- [This Hue Shall Pass：检查整套配色并调整对比度](https://clearleft.com/thinking/fix-the-contrast-without-losing-your-brand)  
  Clearleft 开发的配色检查工具，可将色板中的前景与背景组合生成矩阵，按 WCAG AA 或 AAA 标准检查对比度。对于接近达标的组合，工具可通过调整明度、保持色相来改善对比度，并同步显示变化对其他组合的影响。

- [BagUI：基于 shadcn/ui 的开源组件与页面区块](https://github.com/anelkabag/bag-ui)  
  BagUI 提供导航栏、首屏、页脚、价格表等可复用组件与页面区块，基于 React、Next.js、Tailwind CSS 和 shadcn/ui 构建。项目开放源码，开发者可以复制组件并按自己的设计与业务需求修改。

- [File Viewer：在浏览器中预览 Office、PDF 与 CAD 文件](https://github.com/flyfish-dev/file-viewer)  
  File Viewer 提供 Office、PDF/OFD、CAD、压缩包和邮件等格式的只读预览，支持 React、Vue、Svelte 与 Web Components 集成。内置渲染器在浏览器中解析文件，无需转换服务器，并支持按格式加载引擎及自托管相关资源。

- [Tinkerfont：在真实网页上检查与替换字体](https://tinkerfont.com/)  
  Tinkerfont 是面向 Chrome 和 Firefox 的字体调试扩展，可检查文字的字体属性、扫描页面正在使用的字体，并直接替换字体预览效果。工具支持限定修改区域、上传自有字体，以及按站点保存字体方案。
