## 前端技术
- [Node.js 26 进入 LTS，Node 27 发布首个 Alpha](https://nodejs.org/en/blog/announcements/evolving-the-nodejs-release-schedule)
  <br>Node.js 26 于 10 月 28 日进入 LTS（代号 Lithium），同日 Node 27 发布项目史上第一个 Alpha 版本。按新发布模型，Node 改为每年 4 月发布一个主版本、10 月进入 LTS，所有版本都会成为 LTS，不再区分奇偶数，每个主版本先经历 6 个月 Alpha，期间允许 semver-major 变更。应用团队按 LTS 升级即可，库和工具的维护者建议把 Alpha 加入 CI 矩阵，提前验证破坏性变更。

- [Chrome 157：HTML-in-Canvas 支持绘制交互式 DOM 元素](https://developer.chrome.com/blog/html-in-canvas)
  <br>Chrome 157 发布（官方博客 10 月 26 日，稳定版 11 月 3 日），头条特性是 HTML-in-Canvas，可将实时交互的 DOM 元素绘制到 2D、WebGL 和 WebGPU canvas 中，有大量引人注目的应用场景，是图形渲染领域的重要新能力。此前的 Chrome 156 已不再缓存模块 fetch 失败，因网络或 HTTP 错误失败的动态 import() 现在可以重试，对微前端、按需加载等依赖动态加载的应用是可靠性改进。

- [Safari 27.1：预览 Device Posture 和 Viewport Segments API](https://webkit.org/blog/18486/webkit-features-for-safari-27-1/)
  <br>Safari 27.1 在 iPhone Duo 上以特性开关形式预览 Device Posture 和 Viewport Segments API，让 JavaScript 可检测折叠状态并检查屏幕分段。为折叠屏/多屏设备的前端适配铺路。

- [Node2Shell：Node.js 内置 Brotli 解码器 RCE 漏洞，已现在野利用](https://www.herodevs.com/blog-posts/cve-2026-111497-node2shell-node-js-brotli-rce)
  <br>Node.js 于 10 月 21 日发布 26.12.1、24.22.1 和 22.23.4 三个安全版本，修复 10 个 CVE。其中 CVE-2026-111497（外号 Node2Shell）是内置 Brotli 解码器的越界写入，可导致远程代码执行，Google 的 CVE 记录评分 9.2（CVSS v4）。Imperva 已在官方 24.22.0 镜像上演示执行代码，JavaScript Weekly 在 10 月 27 日提到已出现在野利用流量。只要服务会解压不可信的 Brotli 数据就受影响，已停止维护的 Node 20 及更早版本没有补丁。建议升级到修复版本，重建内嵌 Node 的容器镜像和可执行文件，并重启进程。

- [Rspack 2.3：采用 SWC Next 重写解析器](https://rspack.rs/blog/announcing-2-3)
  <br>Rust 版 webpack 替代品 Rspack 2.3 采用 SWC Next 及其重写解析器，构建速度提升 5-20%，峰值内存占用更少。工程化工具链的重要升级。

- [Vitest 5.1：--since-last-run 只跑受影响测试](https://vitest.dev/blog/vitest-5-1)
  <br>Vitest 5.1 新增 --since-last-run 标志，仅重跑受编辑影响的测试，并加入交互式快照审阅功能。大型测试套件的迭代效率显著提升。

## AI资讯
- [Google 发布 Gemini 4 Carbon：网络安全与长周期任务领先](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon)
  <br>Google 于 10 月 28 日发布 Gemini 4 Carbon，称其为目前最强的模型，在网络安全与长周期任务上尤为突出，在 Artificial Analysis 智能指数 v5.0 上排第一。官方称其生成无漏洞代码的概率约为上一代 Argon 的 2 倍，Chrome 团队称其生成高质量补丁的能力是非 Google 模型的 10 倍以上，WebDev Arena 得分提升 89 分。与 Argon 一样采用分阶段发布，先向网络安全防御方开放，之后才面向开发者、企业和消费者，目前普通用户还用不了。

- [OpenAI 发布 GPT-6.1 Terra：性价比档位升级](https://www.datacamp.com/blog/gpt-6-1-terra)
  <br>OpenAI 于 10 月 26 日发布 GPT-6.1 Terra，取代 GPT-5.6 Terra，面向填表、读发票录入软件、解读技术图纸、视频剪辑等日常电脑操作和沟通类工作。API 价格为每百万 token 输入 1 美元、输出 5 美元，比 GPT-5.6 Terra 和 GPT-6.1 Sol 便宜一半，Terminal-Bench 4.0 得分从 21.5% 升至 50.3%。最难的编码任务仍建议用 Sol 或 Astra，做模型路由时可以把常规步骤交给 Terra，只把最难的子任务升级到上层模型。

- [月之暗面发布 Kimi K3.1 Pro：开源权重追近闭源前沿](https://thenextweb.com/news/moonshot-kimi-k3-1-pro-open-weight-cyber)
  <br>月之暗面 10 月 23 日发布 Kimi K3.1 Pro，是 Kimi K3 的后训练升级版，2.8T 总参数、104B 激活，100 万 token 上下文，支持图像输入，同时提供速度快 2 到 3 倍的 Highspeed 版本。官方称提升主要来自大幅增加的强化学习后训练算力，其公布的数据显示 Terminal Bench 4.0 上超过 GPT-6 Astra、仍落后于 Claude Opus 5.5。因为要开源，训练中去掉了网络攻击相关数据，内部 xdev-bench-hard 得分因此从 90.5% 降到 81.0%。权重承诺 11 月 4 日前放出，据 AI/TLDR 已于 11 月 2 日上线 Hugging Face，开源协议以官方模型卡为准。

- [腾讯混元发布 Hy4 正式版：首次支持视觉理解和电脑操作](https://finance.eastmoney.com/a/202611043921868011.html)
  <br>腾讯混元 11 月 4 日发布 Hy4 正式版，参数规格与 8 月开源的 Hy4 preview 相同（770B 总参数、49B 激活、1M 上下文），升级在于扩大预训练和后训练数据，首次加入视觉理解和电脑操作（Computer Use），并针对 Blender、CAD 等专业软件做了专项训练。API 价格不变，每百万 token 输入 6 元、输出 18 元、缓存命中 0.3 元，腾讯云 TokenHub 五折到 12 月 31 日，WorkBuddy 和 CodeBuddy 在 11 月 4 日到 15 日有免费额度，API 已接入 OpenRouter、OpenCode 等。官方承认与顶尖闭源模型仍有较大差距，权重只说"近期开源"，目前尚未放出，更便宜的 Hy4 flash 也即将发布。部分基准为官方自测，建议等第三方评测。

- [GitHub Universe 2026：Copilot Fusion、Projects 与 Agent Merge](https://venturebeat.com/orchestration/github-copilot-fusion-mixes-models-to-achieve-near-opus-5-5-coding-performance-at-half-the-per-task-cost)
  <br>GitHub 在 10 月 28、29 日的 Universe 大会上把 Copilot 推向"智能体软件交付系统"。Copilot Fusion 正式可用，按任务自动选择并协调多个模型（单模型、级联、互相评审三种执行方式），Standard 档所有套餐可用，High 和 Max 档需 Pro+ 及以上，Fusion 本身不额外收费，模型费用到 11 月 30 日优惠 30%。GitHub 称 Fusion Max 在 Artificial Analysis 编码 Agent 指数上得 60 分，与 Claude Code（Opus 5.5 Max）相差不到 2 分，每个任务成本约一半，这些数据为 GitHub 自己公布。同期发布的还有跨多个仓库协调 Agent 的 Copilot Projects、盯住 PR 并修复 CI、解决冲突、检查通过后自动合并的 Agent Merge，以及 Code Review Max 档位和带花费上限的共享 Automations。第三方解读提醒，Agent 会话和 CI 会占用同一份预算，团队上线前要先设好预算和告警。

- [DeepSeek 提出 Super-agent 架构：Router 与 Worker 双层设计](https://github.com/deepseek-ai/dsh-superagent-prototype)
  <br>DeepSeek Harness 团队 10 月 31 日发布《Super-agent 设计探索》，指出单任务 Agent 已足够强，瓶颈变成人同时只能盯 3 到 5 个会话。Super-agent 要做到连续（跨 IM 和 GitHub 保持同一个 Agent）、高效（并行多任务）、主动（观察事件并自行推进）和持久（云端常驻、异常自动恢复）。架构由 Router/Worker 双层、事件驱动（程序规则加模型判断两级过滤）、异步 ReAct Loop、计算与状态及环境分离（可接入本地机器）和外部 Watchdog 五部分组成。初步实验用约 300 条消息的合成负载，Super-agent 任务完成时间 p50 为 12.4 分钟、p95 为 15.7 分钟，对照的单会话加 Subagent 方案 p95 为 29.5 分钟，代价是缓存读取 token 更多。团队同时开源了原型 dsh-superagent-prototype，强调它只验证技术路线，并非正式产品，安全与隐私等问题仍未解决。

- [TanStack AI 1.0 稳定：供应商中立的 AI 工具包](https://tanstack.com/blog/tanstack-ai-1-0)
  <br>TanStack AI 1.0 稳定发布，提供 useChat() 等 React 钩子、23 个供应商适配器和 MCP 支持，是供应商中立的 AI 工具包，帮助开发者快速构建 AI 应用而不被锁定。

- [GitHub Octoverse 2026：TypeScript 连续登顶，三大语言约四成 PR 有 AI 参与](https://github.blog/news-insights/octoverse/octoverse-commits-pushes-reach-new-highs-in-2026-as-developers-build-with-agents/)
  <br>GitHub 年度报告显示 TypeScript 连续第二年成为贡献者最多的语言，Python 第二、JavaScript 第三。2025 年 9 月到 2026 年 9 月 TypeScript 新增 362 万月活贡献者，Rust 增速翻倍。TypeScript、Python、Rust 三种语言的合并 PR 中约 40% 到 44% 有 AI 参与。提交和推送量创历史新高，开发者正大规模使用 Agent 构建。

- [OpenAI 收购 Pierre Computer：加快 AI 与 Git 协同](https://the-decoder.com/openai-acquires-pierre-computer-company-to-make-git-keep-up-with-ai-coding-agents)
  <br>OpenAI 11 月 4 日宣布收购 Code Storage 等开源工具背后的 Pierre Computer，其库已支持 Codex（Trees 文件导航、Diffs 差异查看、Highlights 实时语法高亮）。交易尚需监管批准，开源项目保持开源。两天前 OpenAI 刚披露自研 Git 后端 Pando，据 AI Weekly 称中位代码推送延迟降低近 80%。反映 AI 编码 Agent 对 Git 工作流工具的需求爆发。

- [用 AI Agent 减少 Next.js 的 JavaScript 体积](https://nextjs.org/blog/ship-less-javascript-with-ai)
  <br>Vercel 发布新 skill，利用 Turbopack 模块图帮助 AI Agent 定位包体积膨胀。AI 编程工具与构建工具链深度结合，是「AI 辅助性能优化」的代表实践。

- [OpenAI 让 GPT-6 Astra 设计硬件设备](https://openai.com/index/accelerating-engineering-for-the-physical-world/)
  <br>OpenAI 11 月 3 日发文披露，团队让 GPT-6 Astra 在没有人工直接修改的前提下，完成一台可与 Codex 对话的设备：定义功能需求，设计外观、外壳结构、PCB 和软件集成。文章同时提到与马自达合作，用模型辅助车头气动外形的模拟与优化。AI 在物理世界工程设计上的能力正在提升。

- [Nolan Lawson 实测：AI 时代各 JavaScript 框架的「AI 成本」](https://nolanlawson.com/2026/10/28/the-ai-cost-of-javascript-frameworks/)
  <br>Nolan Lawson 用 Claude 在 12 个 JS 栈中各构建同一应用 5 次，测试「X 更适合 Agent」的说法。成本区间大多重叠，但浏览器端 JS 中位数差异明显：Astro 0KB、Hono+htmx 18K、SvelteKit 36K、React Router/TanStack Start/Next.js 115-142K。若已「放手」给 Agent，为何坚持特定栈？

## 扩展阅读
- [Web 承受不起 JavaScript 运行时单一化](https://redmonk.com/kholterhoff/2026/10/27/js-runtime-monoculture/)
  <br>Deno 团队 10 月 9 日宣布加入 Cloudflare，运行时再维护一年后停止开发，主要服务端运行时可能缩减为 Node、Bun 和 workerd。分析师引用 IE6、Chromium 垄断和 io.js 分叉的历史，论证运行时单一化值得警惕。另据 JavaScript Weekly，Deno 团队表示正推动 Deno 进入基金会，同时出现新分叉 Ende，计划放弃 Node 兼容性、专注沙箱化。

- [Dan Abramov：为 React Flight 协议加入模糊测试](https://github.com/react/react/pull/37936)
  <br>React 核心成员 Dan Abramov 提交 PR，为 RSC 的 Flight 协议加入模糊测试：随机生成带共享引用和循环的值图，以及模块加载、Promise 完成、流分包、订阅时机等事件调度，用真实的服务端 writer 和 Node、Edge reader 验证结果。失败时会输出可复现命令并自动缩小用例，PR 中暴露已有 bug 的用例先标为跳过，由后续提交修复后重新启用。用模糊测试加固核心协议，对 RSC 生态的稳定很重要。

- [设计系统性能基准：MUI、Mantine、Ant Design、React Spectrum 实测](https://denodell.com/blog/design-systems-should-be-fast-by-default)
  <br>Den Odell 对 10 个主流设计系统做负载测试，在 CPU 降速 4 倍下比较打开 249 个国家下拉框的耗时：Fluent 61ms、Carbon 63ms 最快，Mantine 84ms、Ant Design 134ms 居中，Material UI 208ms、React Spectrum 227ms 明显偏慢，Ionic 最慢（1266ms）。多选勾选测试里 Ant Design 反而最慢（421ms）。同一设计系统在不同任务上快慢不一，也不取决于所用框架。React Spectrum 的问题已提 issue 并有修复在审。性能应纳入设计系统团队的优先级。

- [如何招聘 AI 时代的初级工程师](https://seldo.com/posts/a-proposal-how-to-hire-junior-engineers-in-the-age-of-ai)
  <br>npm 联合创始人 Laurie Voss 提出传统编码面试已死，探讨 AI 时代如何招聘初级工程师。对技术团队的人才策略和面试文化有启发意义。

- [CSS-Tricks 独立回归：Geoff Graham 重新拥有该站点](https://css-tricks.com/css-tricks-has-a-new-owner/)
  <br>备受欢迎的 Web 开发资源 CSS-Tricks 重新独立，由长期编辑 Geoff Graham 拥有。对前端社区而言，经典资源回归是件值得庆祝的事。
